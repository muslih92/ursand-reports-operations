# حفظ قائمة فحص المحطة في قاعدة البيانات (بدل جهاز المشغّل فقط)

## المشكلة المؤكدة
حالياً كل فحص نظام يُحفظ في ذاكرة المتصفح فقط، ولا يصل للنظام إلا عند الإرسال النهائي — وبدون الصور.
النتيجة:
- المشرف لا يرى تقدّم المشغّل قبل الإرسال النهائي.
- الصور المرفقة لا تصل لأحد غير جهاز المشغّل.
- لو مسح المشغّل بيانات المتصفح أو استخدم جهازاً آخر، يفقد عمله.

## الحل المقترح
1. جدول جديد في قاعدة البيانات لسجلات الفحص لكل نظام (المحطة، التاريخ، الوردية، اسم النظام، الحالة، الملاحظة، وقت الفحص، المشغّل) مع صلاحيات: المشغّل يكتب لمحطته، المشرف والأدمن يقرأون محطاتهم.
2. مخزن صور محمي لمرفقات الفحص، وربط كل صورة بسجل النظام الخاص بها (بحد أقصى 4 صور كما هو حالياً).
3. جسر داخل صفحة القائمة: عند حفظ أي نظام يُرسل السجل فوراً إلى النظام ليحفظه في قاعدة البيانات، والصور تُرفع للمخزن المحمي.
4. عند فتح القائمة تُحمَّل سجلات اليوم/الوردية من قاعدة البيانات أولاً وتُدمج مع النسخة المحلية (تبقى النسخة المحلية كاحتياطي أثناء انقطاع الشبكة).
5. لوحة المشرف/الأدمن تعرض الحالة والملاحظات والصور مباشرة أثناء الوردية، لا بعد الإرسال فقط.
6. تنبيه واضح للمشغّل عند فشل الحفظ (بدل التجاهل الصامت الحالي) مع إعادة محاولة تلقائية.

## ملاحظات
- الصور تُرفع كملفات في المخزن المحمي وليست داخل قاعدة البيانات، تفادياً لضخامة الحجم.
- لا تغيير على شكل الواجهة الحالية للمشغّل.
